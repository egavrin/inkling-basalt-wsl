The GSQ release pack converts supported GGUF tensors to the Basalt layout,
preserves the mixed-precision expert weights and embeds DFlash 2.
The MX8 release pack retains the original NVFP4/MXFP8 target weights and
embeds the same DFlash 2 drafter. The part files are consecutive byte ranges
of these two packs. The release manifest identifies each part and assembled
pack by size and SHA-256. See MODEL-LICENSE.txt for the governing license.
